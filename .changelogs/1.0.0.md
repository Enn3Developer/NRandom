First release of NRandom, a sink of random things for GT: New Horizons. 1.0.0 adds one block.

### N Spectre Glass
Glass that only mobs get through. Spectre Glass lets items through as well ([GT-New-Horizons-Modpack#25648](https://github.com/GTNewHorizons/GT-New-Horizons-Modpack/issues/25648)); this doesn't.
- Mobs pass through it. Players, items, XP orbs, minecarts, projectiles and falling blocks don't.
- A mob ridden by a player doesn't pass either, so you can't ride a horse through it.
- Mobs can spawn on top of it, like on Spectre Glass.
- Crafted 1:1 from Random Things Spectre Glass (shapeless).
- Connected textures through Angelica, which GTNH 2.9 ships with them enabled. Without them, every block keeps its own frame.

### Spectre Glass migration
- The first time a chunk loads with NRandom, the Spectre Glass placed in it turns into N Spectre Glass. Each chunk is converted once: Spectre Glass placed afterwards stays Spectre Glass.
- Spectre Glass in inventories, chests or AE2 isn't converted; craft it 1:1.
- To keep your Spectre Glass, set `B:migrateSpectreGlass=false` in the `general` section of `config/nrandom.cfg` before the first start with NRandom.

### Setup
- Install the same version on the server and on every client. Built against GTNH 2.9.0-RC-2 (Random Things 2.7.11, Angelica 2.2.28).
- Random Things provides the recipe and the migration; without it, N Spectre Glass has neither.
- English and Italian translations.
